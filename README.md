# ✈️ Бумажный Самолётик

Генератор случайных путешествий. Нажми на кнопку — и самолётик унесёт тебя в случайную точку мира или в уютные уголки Румынии.

## 🌍 Что внутри
- 8 локаций в радиусе 3 км от Нэводари (Румыния) + 5 городов мира
- Красивая анимация полёта самолётика
- Карточка с фактами, вибрацией и расстоянием
- Адаптивный дизайн под телефон и компьютер

## 🚀 Как запустить
1. Скачай все файлы
2. Открой `index.html` в браузере
3. Наслаждайся!

## 🛠️ Технологии
- HTML + CSS (анимации, градиенты, blur)
- Ванильный JavaScript (без библиотек)
